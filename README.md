An interactive web app designed to help people learn
Manchu. Based on ["An Online Self-Study Introduction to Manchu in 21 Lessons"](https://www.manchustudiesgroup.org/introduction-to-manchu-in-21-lessons/)
provided by the Manchu Studies Group.

Features/Roadmap:
- [ ] Allow users to type in Manchu
- [ ] Implement the text of all 21 lessons
- [ ] Allow users create an account
- [ ] Allow users to save their progress
- [ ] Allow users to draw Manchu script
